# Cupang Detail Image Studio

와이홉·유앤채 상세페이지를 개인 PC의 Codex로 제작하는 작업실입니다.

**사용자가 하디 채팅에서 제품 사진 제공 → TYPE1~7 선택 → 프롬프트 수령까지 진행하면, Codex가 이후 이미지·영상·자막·Figma 배치·검수·출력을 수행하는 것이 목표입니다.** 웹 서비스나 별도 이미지 API 과금 구조를 기본으로 만들지 않습니다.

## 시작

이 저장소를 Codex 프로젝트로 열고 다음처럼 요청합니다.

> 이 저장소의 워크프로세스로 제작 시작. 브랜드는 와이홉, TYPE6. 아래는 하디에서 받은 최종 프롬프트이고, 첨부한 사진이 원본 제품 사진이야. 이미지·리드 영상 2개·Figma 상세페이지·최종 출력까지 진행해줘.

Codex는 `AGENTS.md`와 프로젝트 스킬을 읽고 사진·원고를 저장해 작업을 진행합니다. 사용자가 별도로 JSON을 쓰거나 이미지·영상·문구를 수동 배치하는 방식이 아닙니다. 이전 작업은 작업 ID로 이어서 실행합니다.

## 들어 있는 것

- TYPE1~7 원본 .fig를 해석한 구조 목록과 예외 규칙
- 브랜드·이미지 공급자·Flow·Figma 운영 설정
- 원고 분리, 작업 검증, 생성 계획, 초별 자막, 재개 상태 관리 도구
- 5개 구간을 정확히 5초로 조립하는 영상 편집 도구
- 리드 2개 샘플 검증과 전체 제작 재개를 분리하는 실행 범위
- live Figma 검사·복제·텍스트 수정용 실행 코드 생성기
- Codex 프로젝트 스킬과 작업 시작 지침

## 현재 검증 범위

로컬 템플릿의 3,295개 노드와 TYPE1~7 구조를 해석하고, 사용자 계정에 마스터 사본을 가져와 실제 Figma 도구에서 전체 타입 연결을 확인했습니다. 실물 TYPE6 리드 샘플에서는 이미지 생성 → Flow 소재 생성 → 리드별 5초 편집·한글 자막 → Figma MP4 삽입까지 실행했습니다. Figma의 네이티브 **File → Place image/video**로 넣은 두 영상은 프로토타입의 실제 영상 DOM과 화면으로 재생을 확인했습니다. 각 최종 MP4는 768×500·30fps·150프레임입니다.

검증 범위는 **리드메시지 1·2 샘플**입니다. 샘플 QA가 모두 통과한 상태는 `sample_verified`이며 `page_complete:false`입니다. 전체 상세페이지 제작·납품은 아직 실물 작업으로 검증하지 않았습니다. After Effects용 JSX는 준비했지만 실제 AE 실행·렌더는 검증되지 않았고, 현재 편집 MP4는 FFmpeg 결과입니다. 현재 PC의 연결 상태와 작업 증빙은 gitignore된 `.local/`·`jobs/`에 저장합니다.

실행에 필요한 조건은 편집 가능한 Figma 파일, 로그인된 Flow, 요청한 Image 2.5 high를 실행할 수 있는 이미지 도구입니다. 현재 Codex 내장 이미지 도구로 해당 모델·품질을 직접 지정할 수 있는지는 확인되지 않았습니다. 이번 샘플은 사용자가 허용한 내장 도구 대체 실행으로 진행했으며, 이를 Image 2.5 high 사양 확인으로 취급하지 않습니다. 대체 허용은 작업별로 기록합니다. 구독과 크레딧에는 서비스 한도가 있으며, 무제한·비용 0을 보장하지 않습니다. 별도 유료 API 자동 전환과 크레딧 자동 구매는 꺼져 있습니다.

Figma의 현재 `upload_assets`는 이미지용입니다. MP4는 검증된 네이티브 파일 삽입을 우선 사용하고, 가져온 VIDEO fill 노드 자체를 작업 사본으로 옮깁니다. 현재 연결에서 `use_figma`로 VIDEO fill을 직접 쓰는 방식은 지원되지 않았습니다. 프로토타입 재생을 확인한 뒤 GIF 대체본은 숨깁니다. 최종 동영상은 MP4와 재생 가능한 HTML 미리보기로도 제공하며, 정지 이미지 출력에 영상이 포함되었다고 보고하지 않습니다.

Figma 인증은 연결된 플러그인과 기존 브라우저 세션을 재사용합니다. 작업마다 로그인하거나 로그아웃하지 않습니다. 서비스가 인증을 만료시켰을 때만 정상 재인증이 필요합니다. 비밀번호를 저장소에 보관하지 않습니다.

이미지 검수에는 Pillow가 필요하며 Codex 제공 Python 런타임에 포함되어 있습니다. 별도 환경에서는 `requirements.txt`를 설치합니다. Windows 영상 도구는 `scripts/setup-media.ps1`로 프로젝트 `.tools/`에만 설치할 수 있습니다. 템플릿 Pretendard가 없으면 `figma_payload.py clone --font-fallback "Noto Sans KR"`로 사본에서만 지원 글꼴을 적용할 수 있습니다. 실제 리드 사본의 한글 렌더·줄바꿈 및 마스터 보존을 확인했습니다.
