# 고정 얼굴과 변경 가능한 스타일

와이홉·유앤채의 착용 이미지와 영상에서 사용하는 얼굴은 F01(여자), M01(남자) 두 프로필이다. 기준 사진은 `.local/models/`에 보관하고 공개 저장소에 올리지 않는다. `config/models.json`에는 버전, SHA-256, 승인 상태와 외모 특징만 기록한다.

F01은 사용자가 “여자는 굿 고정”으로 승인한 기준 얼굴이다. M01-v6은 사용자가 “이 얼굴로만”이라고 마지막으로 지정한 단독 남자 사진 자체다. 원본 얼굴을 기준으로 저장하며 거절한 v1~v5 생성 후보를 얼굴 참조에 섞지 않는다. 의상 변경 시험 이미지도 기준 얼굴을 대체하지 않는다. 파생 결과는 원본과 비교하여 정체성 변화를 검수한다.

얼굴 정체성은 고정하고 옷은 고정하지 않는다. 제품, 계절과 촬영 콘셉트에 맞춰 현대적인 한국 패션 화보 스타일로 바꾼다. 매 작업마다 같은 가죽 재킷이나 니트를 반복하도록 만들지 않는다. 하나의 연속 장면 안에서는 의상·액세서리를 유지하여 영상 연결을 자연스럽게 만든다.

생성에 반드시 실제 기준 얼굴 사진과 원본 제품 사진을 함께 첨부한다. 앞·옆 착용 컷도 승인된 기준에서 파생하고 얼굴 형태·눈매·코·입·피부 톤을 비교한다. 장면별로 다른 남녀 얼굴을 새로 만드는 방식은 사용하지 않는다. 모자·색·홀·로고·봉제 등 제품 특징은 별도로 검수한다. AI 생성은 참조가 있어도 얼굴과 제품이 달라질 수 있으므로 실제 결과 확인을 생략하지 않는다.

Codex가 작업을 인수하면 다음 도구로 새 job 버전을 만든다. 사용자가 직접 입력할 절차가 아니다.

```powershell
python scripts/models.py status
python scripts/models.py bind jobs/sample/job.json --workspace jobs/sample --output jobs/sample/job-f01.json --model-ids female-f01
```

`--model-ids`를 생략하면 F01/M01 기본 배정을 사용한다. 미승인 후보, 해시가 다른 사진, 기존 job 덮어쓰기는 거부한다. 계획은 참조 사진을 작업의 `input/models/`에 복사하고 모델 배정과 해시 변경을 감지한다. 얼굴이 바뀌면 이전 영상의 QA를 그대로 재사용할 수 없다.

다른 PC에서는 비공개 기준 사진을 같은 경로에 복원한다. 기준 사진이 없을 때 설명만 보고 얼굴을 다시 생성하지 않는다. 모델 교체 요청은 새 버전으로 기록하고 이전 승인 얼굴과 제작 이력을 보존한다.
