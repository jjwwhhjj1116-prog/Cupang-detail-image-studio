정적 초기화는 실제 Python으로 `scripts/setup_portability.py --repo .`를 실행해 기존 PC ID·연결 보존을 확인했다. 설치기 테스트는 두 Windows 셸에서 같은 5개 테스트를 수행했고, 위 표의 공백 경로는 신규 설치 테스트에 포함된다.

재설치 백업은 스킬 검색 폴더 밖에 보관하며, 검색 폴더에 실제 설치 스킬 한 개만 남는 검증도 통과했다.

기본 패키지의 네 종류는 흰배경 제품 단독 대표 PNG, 편집 가능한 Figma 작업 링크, Figma 전체 PNG, 같은 제품정보의 별도 PNG다. 영상 CLI와 기존 검수는 영상 추가 요청에 적용한다.

이 기록의 파일 검사는 실제 생성 품질이나 live Figma 편집 권한의 대체 증거가 아니다. 이번 설정 작업에서는 새 상품으로 실제 GPT 응답 → 생성 → Figma → 4종 전체 제작을 실행하지 않았다. 다른 물리 PC의 설치·로그인·최종 제작도 미검증이다.

관찰한 GPT 정보에는 12월 11일 종료와 제작자 플러그인 이전 안내가 있었다. 공개 GPT URL은 확인되지 않았고 현재 동작은 고정 GPT 항목으로 접근한다. 실제 제작 시작 때 해당 서비스/후속 플러그인 연결을 재확인한다. 스킬 설치는 서비스의 장래 가용성을 보장하지 않는다.
