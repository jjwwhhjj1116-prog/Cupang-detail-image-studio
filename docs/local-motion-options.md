# 로컬 타이포그래피·모션그래픽 도구

2026-10-05 확인. 이 작업은 Flow에서 제품 영상을 생성한 다음 PC에서 글자·컷·속도를 편집한다. 글자만 수정하는 경우 Flow를 다시 생성하지 않는다. 로컬 편집은 Flow 생성 크레딧을 사용하지 않는다. Flow 원본 생성 비용과 PC 처리 시간은 별도다.

## 현재 실행 경로: FFmpeg + Gmarket Sans Bold

프로젝트의 FFmpeg/libass 편집기는 설치된 로컬 실행 파일과 공식 Gmarket Sans Bold TTF를 사용한다. 전체 화면 영상 위에 텍스트를 합성하고 최종 5초·30fps·150프레임 MP4를 출력한다. 검은 자막 띠 없이 제품과 얼굴의 여백을 보고 글자를 배치한다. 실제 글꼴 선택 로그와 출력 프레임을 검수한다.

이 경로는 현재 구현·시험된 편집 경로다. 상세 실행법은 [fullbleed-v2.md](fullbleed-v2.md)를 따른다. 실제 제품 샘플은 파일별 QA가 통과해야 납품 완료다.

## 확장 선택지: Remotion + 공식 Agent Skills

[Remotion 공식 Agent Skills](https://www.remotion.dev/docs/ai/skills)는 Codex 등의 에이전트가 프로젝트 구성, React 기반 애니메이션, 타이포그래피, 미디어, 글꼴, 타이밍과 렌더링을 다루도록 안내한다. 전체 지침은 `remotion-best-practices`, 세부 작성은 `remotion-markup`, 렌더는 `remotion-render` 등의 스킬로 제공된다.

영상 편집 자동화에 적합한 확장 후보이며, 문서 작성 시점에는 이 저장소에 Remotion 런타임이나 해당 스킬을 설치·실행하지 않았다. 스킬 자체는 렌더러가 아니므로 런타임 설치, 폰트·영상 연결, 로컬 렌더와 시각 검증이 별도로 필요하다. 설치만으로 영상의 디자인 품질이 보장되지는 않는다.

[공식 라이선스 안내](https://www.remotion.pro/license)는 개인 및 3인 이하 회사의 무료 상업적 사용·자동화를 허용하고, 무료 조건에 해당하지 않는 조직에 Company License를 요구한다. 서비스 판매나 조직 규모 변경 시 해당 조건을 확인한다. 모든 사업 환경에서 무조건 무료라고 약속하지 않는다.

## After Effects

프로젝트는 편집 가능한 컴포지션을 만들기 위한 JSX 준비 경로를 제공한다. 현재 작업에서 AE 실행·AEP 저장·AE 렌더 성공은 확인되지 않았다. FFmpeg 결과를 AE로 제작했다고 표시하지 않는다. AE가 실제 설치된 환경에서는 JSX 실행과 결과 검수를 별도로 진행할 수 있다.

## 제작 기준

1. Flow: 리드마다 장면 지시를 포함한 원본 1회 생성, 출력 수 x1과 화면의 비용 기록.
2. 로컬: 실제 장면 구간 확인, 제품 변형 컷 제외·보정, 5초 편집.
3. 로컬: Gmarket Sans Bold의 핵심 단어와 보조 문구를 영상 위에 합성. 원문과 편집 카피 변경 이유 보존.
4. 검수: 제품·얼굴 가림, 한글 글꼴, 움직임, 각 초 경계, 총 길이 확인.
5. 출력: 사용자가 독립적으로 내려받는 MP4와 Figma 배치용 파일 제공.

기존 생성물로 컷을 보정한 경우 원본 출처와 사용 구간을 기록한다. 한 번 생성했다는 비용 기록과, 최종 영상에 실제 사용한 소스의 개수는 서로 다른 정보다. 자동으로 장면별 5회 재생성으로 전환하지 않는다.
