# PC 간 워크프로세스 설정 검증

검증일: 2026-10-05. Windows에서 현재 작업본과 개인 설정·도구·작업 이력이 없는 새 작업본으로 검사했다. 실제 다른 PC 3대의 인증까지 대신 완료했다는 의미는 아니다.

| 검사 | 결과 |
|---|---|
| 전체 Python 테스트 | 115개 통과 |
| 기존 작업본 `setup-studio.ps1` | 로컬 검사 12개 통과, `local_setup_ready` |
| 기존 작업본 `-CheckOnly` | 네트워크 설치 없이 통과 |
| 공개 대상 파일만 복사한 새 작업본 | 도구·스킬·npm·렌더 브라우저 설치 및 검사 통과 |
| 새 작업본 반복 실행 | 유효한 설치와 PC 식별자 재사용, 정상 통과 |
| Python·Node 없는 경우 | 한글·공백이 있는 별도 폴더에서 portable Python 3.12.10/Pillow 12.3.0·Node 22.15.0 설치 통과 |
| Portable Python | 실제 PNG 저장/읽기와 형제 모듈 import 통과 |
| 고정 FFmpeg·글꼴 | 9.0.2와 Gmarket Sans Bold의 파일 해시·실행 검증 통과 |
| 기본 Skill Installer 없는 경우 | 공식 고정 커밋의 Remotion 스킬 12개와 지원 자료 자동 설치 통과 |
| 모델 참조 | 승인된 남녀 얼굴·캐릭터·표정 시트 6개가 `.local` 없이 검증됨 |
| 설치 경로 | Windows PowerShell 5.1의 260자 초과 경로와 한글 경로 테스트 통과 |
| 작업 경계 | 기존 연결 파일 보존, PC별 작업 ID 분리, ZIP 경로 탈출·손상 파일 거부 테스트 통과 |

검증 중 기존 Remotion 미리보기가 사용하던 파일로 npm 재설치가 막히는 상황을 확인했다. 유효한 기존 설치를 버전 검사 후 채택하도록 보완했다. 불완전한 기존 설치는 해당 저장소의 미리보기 종료 후 복구하고 다시 검사했다.

도구는 프로젝트의 `.tools`에 준비하며 사용자 전역 PATH·레지스트리·계정 비밀번호를 변경하지 않는다. 공통 코드·설정·모델 참조와 PC별 실행 경로·계정 연결·작업 이력을 분리한다.

로컬 검사 보고서는 항상 `production_ready: false`와 `live_verification_required`를 남긴다. 실제 PC마다 Codex 이미지 도구, Figma 플러그인·마스터 편집 접근, Flow 로그인·크레딧, 브라우저 업로드를 확인해야 한다. 검사에서는 새 상품 이미지·Flow 영상을 생성하거나 전체 Figma 상세페이지를 완료로 기록하지 않았다. 실제 상품 결과의 얼굴·제품·영상·레이아웃 검수는 각 제작 작업에서 수행한다.
